## 两张附件

1. 在已安装双羽输入法的鸿蒙设备或模拟器上，打开系统设置中的输入法列表并截图。需要能看到双羽输入法；不是键盘皮肤页面。
2. 在 DevEco Studio 中打开项目的 `entry/src/main/module.json5`，截取 `extensionAbilities` 下 `Stage0InputMethodAbility` 的配置，保留 `type: inputMethod`、`srcEntry` 和 `ohos.extension.input_method` 元数据。获批前暂不填写虚构的 dataGroupIds。

## 获批后下载新 Profile

1. 按华为回复取得实际 data-group-id。
2. 登录管理此应用的 AppGallery Connect，进入“证书、APP ID和Profile → Profile”，按回复指引更新/重新获取该应用的开发和发布 `.p7b` 文件。后台菜单路径可参考[华为 Profile 管理说明](https://developer.huawei.com/consumer/cn/doc/doccenter-operations/agc-help-package-errorcode-0000002312513009)。
3. 为已有应用保留原来的签名身份，继续使用对应的证书和密钥。此次目的在于获取共享授权后的 Profile；无需因为这次权限申请而废除证书、重建密钥或创建另一个应用。
4. 将获批 ID、华为回复和新 `.p7b` 文件的本机路径提供给开发侧。开发侧检查新文件确实包含该 ID，再配置工程和重新打包；仅重新下载一份不带授权的旧 Profile 不能启用共享沙箱。

已有 `.p12`、证书和密码在本机已配置，本次无需把它们放进申请邮件。
