## 🚀 使用方法

### 方法1：直接导入（推荐）

1. 打开输入法设置
2. 进入"用户词库管理"
3. 点击"导入"按钮
4. 选择对应的模板文件
5. 确认导入

### 方法2：手动复制内容

1. 用文本编辑器打开模板文件
2. 复制需要的内容
3. 在输入法设置中选择"导入文本"
4. 粘贴内容并保存

### 方法3：组合使用多个模板

你可以同时使用多个模板，例如：

```bash
# 组合通用词库 + 开发者词库
cat 01-general.txt 02-developer.txt > my-lexicon.txt
```

然后导入 `my-lexicon.txt`

## ✏️ 自定义和修改

所有模板都可以根据个人需求自由修改：

1. **添加词条**：在文件末尾添加新行
2. **删除词条**：删除不需要的行
3. **修改操作**：更改操作标记（无标记、#删、#固、#数字）
4. **调整优先级**：通过改变行顺序或操作标记

### 示例：个性化开发者词库

```text
# 在02-developer.txt基础上添加你常用的框架
Nest.js	Nest.js	#固
Nuxt.js	Nuxt.js	#固

# 添加公司内部术语
微服务网关	wei fu wu wang guan	#固
```

## ⚠️ 注意事项

1. **不要贪多**：词条太多会影响性能，建议控制在500条以内
2. **定期清理**：删除不再使用的词条
3. **备份重要词库**：定期导出保存
4. **测试后使用**：导入后测试几个常用词是否正常
5. **避免冲突**：固定词不要设置太多（建议<20个）

## 🔧 问题排查

### 导入失败

- 检查文件编码是否为UTF-8
- 确认使用TAB键分隔，而非空格
- 检查是否有格式错误的行

### 词条不生效

- 确认编码拼写正确
- 检查是否有重复定义（后面的会覆盖前面的）
- 尝试重启输入法

### 候选顺序不对

- 复习操作优先级：删除 > 固定 > 定位 > 普通
- 检查固定词数量是否过多
- 验证位置编号是否正确
