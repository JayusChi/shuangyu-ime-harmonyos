# Quanpin lexicon coverage V2 evaluation provenance

Version: 2.0.0. Authored: 2026-08-14 (Asia/Shanghai).

This PROJECT-INTERNAL-AUTHORED-DATA dataset was written independently from the production V2 source. It was not copied from a commercial IME, web corpus, current engine output, old V1 dataset, or the V2 production TSV. Ordinary lexical overlap is expected where both independent lists describe the same public term. The dev split may be inspected during development. The blind split may be executed only after implementation freeze and only through the one-shot gate, which performs three internal repetitions and writes an immutable receipt.
