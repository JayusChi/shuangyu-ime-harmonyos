# Quanpin context reranking V2 dev provenance

This 40-case development set was independently hand-authored on 2026-08-17 to exercise clean, modern colloquial, proper-name, long-sentence, and ambiguous input. It was not copied from either historical blind set, from the production lexicon TSV sources, or from the generated n-gram table. Context entries describe only formal candidates that the evaluator explicitly selects before the target input.

The set is development-only. It is not a blind set, does not support a blind-quality claim, and must receive a new dataset ID and manifest path after any byte change.
