# 全拼正式大词库 V3

> 生效日期：2026-08-28。本文是当前正式口径；V2 文档保留为历史冻结记录。

## 结果

正式 `production.lex` 已由袖珍词库升级为多层生产词库：

- 366,660 个去重词条；
- 274,865 个拼音键；
- 24,049,458 bytes；
- 词库版本 300；
- SHA-256 `005169f6050d45f93dd511d7de183338419419b67fb3556065b15432b0522a41`。

来源层包括 Apache-2.0 的 Rime 基础词库和项目热词/领域词，以及 MIT
许可的 Jieba 0.42.1 词频表。Jieba 读音由固定的 pypinyin 0.55.0 wheel
离线生成，不依赖构建机的 Python 包，也不在设备端解析文本词库。

## 候选呈现

26 键全拼的正式候选页由 7 条改为 50 条。候选栏可横向滚动；展开面板显示
当前 50 条并提供上一页、下一页。高重码音节 `ji` 的回归要求首屏 50 条、
存在后续页，并包含“及、级、即、几、机、既、急、集、记、极”等常用字。

## 确定性与发布身份

`scripts/build-lexicon.ps1` 是标准正式构建入口，连续两次生成完全相同的
24,049,458-byte 二进制。`scripts/build-quanpin-lexicon-v2.ps1` 保留各领域
隔离 profile，并在正式词库变化时同步重建版本绑定的上下文模型。

当前上下文模型为 64,300 bytes，SHA-256
`15b55101d77a87a64d2d414f96147291f7e260a138c98ecbea1d38af2f17b05f`。
应用资源安装器和 Release HAP 门禁均固定校验上述大小与 SHA-256。
