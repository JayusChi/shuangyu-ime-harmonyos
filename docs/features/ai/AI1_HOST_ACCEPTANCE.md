## 每个受支持宿主的执行步骤

1. 新装或重置后确认 AI 总开关、云 AI、本地关联均关闭；完成中文、英文、数字、候选、删除、换行和撤销，确认普通输入无回退。
2. 只打开本地关联，完成若干短句上屏；确认建议标识为 `关联·本地`、最多 3 条、重复操作顺序一致。关闭开关后确认恢复原候选行为。
3. 在批准的云配置下完成当前版本同意，逐一执行续写、精简、礼貌、正式、翻译；确认只有点击动作才发请求，建议标识为 `AI·云端` 且最多 3 条。
4. 分别在加载中继续输入、移动光标、修改原文、隐藏键盘、停止会话、切换编辑器和重复发起动作；确认旧结果不出现、不写入。
5. 模拟断网、8 秒超时、取消、HTTP 错误、空/超长/非法/协议不匹配响应、重复 ID、乱序和迟到；确认固定脱敏错误且普通输入、本地关联可用。
6. 接受 emoji、代理对、组合字符、换行和成对符号建议，再执行一次撤销；确认替换/撤销完整，无半个字符和误删。
7. 让服务返回 `$cmd`、URL、HTML、协议字符串；确认只插入普通文本，不启动应用、不访问网络、不解释命令、不自动发送。
8. 切换 BASIC/FULL/UNKNOWN 和敏感编辑器，确认只有 FULL 的受支持普通文本编辑器允许云动作。

## 证据要求

每一格分别保存设备型号/系统版本、宿主版本、构建 SHA-256、设置快照、操作录屏或截图、结果和失败日志。日志必须脱敏，不得包含输入或建议正文。未执行、环境缺失或代理未配置时只能写 `NOT_RUN`，不能写 PASS。
