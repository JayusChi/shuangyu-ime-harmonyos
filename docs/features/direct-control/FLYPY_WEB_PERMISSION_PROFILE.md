# 应用内小鹤网页权限配置

2026-09-11 用户明确批准：“允许接入应用内查形页并增加联网权限”。手机模拟器自带浏览器在冷启动处理网址时可复现全屏空白，独立 ArkWeb 页面冷启动能够完整显示查形结果，因此采用本配置。

## 产品行为

- `oix` 光标查形、经系统粘贴按钮授权的剪贴板查形，以及小鹤官网/帮助直通，使用非导出的 `FlypyWebAbility`。
- 只接受 `https://flypy.cc` 精确域名，保留原路径、查询字符和片段；不接受相似域名、用户信息段、文件或脚本地址。
- 以新的 LocalStorage 请求序号接收重复查形，网页占满内容区，提供返回、刷新、关闭及载入失败重试。
- 网页没有原生 JavaScript 桥接、文件访问或输入法状态接口。其他网站的链接经用户点击后交给系统浏览器。没有自动读取剪贴板或上传输入历史的新增逻辑。

## 权限边界与发布检查

HarmonyOS 的 INTERNET 是应用级权限，不能声称由系统仅授予某个页面。此产品批准的使用范围是用户主动打开的小鹤网页，包括网页本身的正常资源请求；网络权限不代表云输入、AI 或语音功能已批准启用。

模块声明 `shuangyu.web.permission.profile=flypy-web-v1`。源码及最终 HAP 检查都要求权限恰为 `VIBRATE` 和 `INTERNET`，并要求 `FlypyWebAbility` 不导出。麦克风、额外权限、缺失/未知配置及其他源码位置的权限声明仍被拒绝；发布负向测试覆盖这些情况。

本配置取代旧版本“Release 不声明 INTERNET”的规则，不改变此前历史交付物的验收结论。
