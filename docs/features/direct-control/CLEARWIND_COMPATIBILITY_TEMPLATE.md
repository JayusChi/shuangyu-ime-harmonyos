# 清风直通与快符兼容模板

本文记录 HarmonyOS 版已接收的清风语义。客户可继续把原始 `$CC/$cmd/$ddcmd` 行集中放在“5.直通”分类中；导入器从受支持行保留编码、候选标题和顺序，并把语义转换为类型化动作数据。运行时不会解释任意脚本，动作类型与目标仍受可信白名单约束；增删受支持行无需修改 Rust 内置编码。

## 标记规则

- 功能动作不要追加 `#直`。`#直` 仅用于普通词条的“精确编码可查、万能键不可枚举”语义。
- 候选显示和实际上屏可以不同。例如 `oba` 显示 `横_一`，选中后上屏 `一`。
- 同码可以配置多个动作候选，例如 `orq`、`ouj`、`ojj` 和 `oej`。

## 已实现直通

| 编码 | 候选 | 执行结果 |
| --- | --- | --- |
| `oba` | `横_一` | 上屏 `一` |
| `orq` | `日期 YYYY-MM-DD` | 上屏当前公历日期，如 `2026-08-24` |
| `orq` | `日期 YYYY年M月D日` | 上屏当前本地日期，月、日不补零 |
| `ouj` | `时间 HH:mm:ss` | 上屏当前 24 小时时间（含秒） |
| `ouj` | `时间 HH时mm分ss秒` | 上屏当前中文时间（含秒） |
| `ouji` | `Unix 时间戳` | 上屏当前 Unix 秒级时间戳 |
| `jysi` | `「静夜思」` | 上屏内置诗文 |
| `ojj` | `<熟手词库>` | 只启用核心分类 |
| `ojj` | `<常规词库>` | 恢复本系统默认分类组合 |
| `ojj` | `<初学词库>` | 启用全部系统分类 |
| `oej` | `<二简次选>` | 启用二简次选分类 |
| `oej` | `[关闭二简次选]` | 关闭二简次选分类 |
| `odr` | `[导入用户词库]` | 重新导入设置中已授权、已启用的词库文件源，并重载用户词库 |

分类预设使用 HarmonyOS 版现有分类 ID，不依赖清风的 `flypy/qmc/qmz/upz` 内部名称；每次变更通过设置服务原子保存并立即应用。

## 已实现快符

快符以分号引导：

| 输入 | 结果 | 输入 | 结果 |
| --- | --- | --- | --- |
| `;;` | `：` | `;q` | `：“` |
| `;w` | `？` | `;e` | `（` |
| `;r` | `）` | `;t` | 文本制表符 `\t` |
| `;y` | `《` | `;u` | `》` |
| `;i` | 安全撤销上次上屏 | `;o` | 成对 `「」` |
| `;p` | 成对 `〈〉` | `;a` | `！` |
| `;s` | `……` | `;d` | `、` |
| `;f` | 重复上次上屏 | `;g` | `·` |
| `;h` | 成对 `《》` | `;j` | 成对 `“”` |
| `;k` | 成对 `（）` | `;l` | 成对 `〔〕` |
| `;z` | `“` | `;x` | `→` |
| `;c` | `”` | `;v` | `——` |
| `;b` | 全角空格 `　` | `;n` | 移到当前行末 |
| `;m` | `@` |  |  |

成对符号一次性插入并把光标放在中间，不模拟方向键。系统记录右半符号、会话和 120 秒有效期，跳出前再次核对编辑器内容；嵌套成对符号逐层跳出。

物理 Tab 的顺序为：有组合/候选时取消组合；否则有有效成对符号时跳到右符号之后；否则不消费，让宿主执行原生 Tab。无组合时 Enter 也优先跳出有效成对符号。`;t` 是快符文本动作，不等同于物理 Tab。

## 当前未实现或存在边界

- `onl` 农历日期尚未实现，缺少已经冻结和验证的农历换算数据/算法。
- 不执行任意 `$CC/$cmd/$ddcmd`，也不执行 Wind CLI、动态表达式、剪贴板反查或 `last/url` 脚本。
- Windows 的 `calc.exe`、`mspaint.exe`、`control.exe`、`notepad.exe`、盘符路径、Win+V、静音虚拟键和任意按键序列不适用于 HarmonyOS。
- 自定义网页和鸿蒙目录使用结构化的 `#网页` / `#目录` 词条，见 [创建方法](CUSTOM_SHORTCUTS.md)。动态字典查询及 Windows 命令脚本仍不解释执行。
- 主题、候选布局、全半角、简繁、嵌入编码等清风私有开关不能按原命令一比一迁移，需要分别映射 HarmonyOS 版设置。
- `odr` 的目标是独立的用户词库层，不能把文件写入或覆盖签名的系统分类。若要求“每个外部文件绑定一个可单独开关的用户分类”，需新增按分类保存的用户覆盖层协议。
- `;t` 会请求插入字面制表符，个别宿主编辑器可能拒绝或改写它。
- Tab 跳出采用先同步判断、再异步核对编辑器的安全流程；如果两步之间宿主移动了光标，系统会拒绝错误跳转，但本次 Tab 已被输入法消费。
