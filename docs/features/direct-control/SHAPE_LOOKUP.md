# 网页查形直通 oix

在小鹤音形中文模式输入 `oix`，选择第一个「查」候选，打开 [小鹤查形网页](https://flypy.cc/ix/)。

- 优先取光标前已输入的最后一个汉字；没有可用汉字时，读取剪贴板开头的一个汉字。
- 候选提示显示为「查」：你（以实际查询字为准）。无法直接读取剪贴板时显示「查」：剪贴板；选择后进入主应用的「粘贴查形」页，点击系统粘贴按钮后再读取并打开网页。
- 支持扩展汉字（例如 `𠮷`），查询字符经 URL 编码。编码 `oix`、候选提示、整段编辑器文字不会上屏或作为查询参数。
- 输入编码只显示候选，选择候选后才打开网页；不会随候选更新自动打开。先清理输入法自己的预编辑，再切换到网页。预编辑清理失败时不拉起浏览器。
- 普通应用包不声明受限的 `ohos.permission.READ_PASTEBOARD`，也不调用运行时权限申请。查形页使用 `PasteButton` 的临时授权，只在点击成功后读取；没有可用汉字或粘贴授权失败时提示重试。普通输入不读取剪贴板。

原始词条：

```text
$cmd(run(https://flypy.cc/ix/?q={cursorbefore}{clip}),「查」：{last_0})	oix
```

上面的分隔符表示一个 Tab。词条通过现有导入器转换为闭集 `url.open / flypy-shape` 动作；原始 `$cmd` 不被解释执行。网页与字段来自用户提供的指令。
