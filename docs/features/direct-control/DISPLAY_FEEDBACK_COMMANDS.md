# 候选显示、键高和反馈直通

输入下列编码后，按候选编号或点击候选执行设置。候选标签只用于展示，执行时不会作为文字上屏。

| 编码 | 第 1 项 | 第 2 项 | 第 3 项 |
| --- | --- | --- | --- |
| `ohx` | `[固定]`：候选栏 | `[浮动]`：输入框下方 | — |
| `ojg` | `[键高1.0]`：恢复 1.0 倍 | `[+0.05]` | `[-0.05]` |
| `ojz` | `[键字12号]`：键盘恢复 12 号 | `[+2]` | `[-1]` |
| `ohz` | `[候字15号]`：固定候选恢复 15 号 | `[+2]` | `[-1]` |
| `ofz` | `[浮字17号]`：浮动候选恢复 17 号 | `[+2]` | `[-1]` |
| `ofa` | `[音形]` | `[双拼]` | `[全拼]` |
| `ovd` | `[震动_开]` | `[关]` | — |
| `oyx` | `[音效_开]` | `[关]` | — |

增减操作基于当前已保存的数值叠加。例如连续两次选择 `ojg` 第 2 项，将 1.0 倍调至 1.1 倍。键高沿用 0.8–1.2 倍范围，步进扩展为 0.05；键盘字号范围为 8–32 号，候选字号范围为 10–32 号。到达范围边界后继续增减保持边界值。

固定和浮动候选字号分别保存，切换候选位置或恢复其中一套的默认字号不会修改另一套。设置页也提供键高和两套字号的滑块。

`ofa` 在 26 键小鹤音形、小鹤双拼、全拼中均可使用。候选顺序固定为 1.[音形]、2.[双拼]、3.[全拼]，分别选择 `xiaohe-yinxing-26`、`xiaohe-26`、`quanpin-26`，保存后可继续用同一码切换。双拼和全拼只共享这一条内置方案菜单，其余内置设置直通仍由音形动作表提供。

按键音强度通过设置页「按键音量」调节，范围 0–100%，默认 16%，与 `oyx` 的开关独立保存。播放使用媒体音频流，因此最终响度还受系统媒体音量影响。震动开启时保留当前非关闭档位；从关闭开启时使用轻震动，强度仍可在设置页调整。

设置结构版本升级到 22，缺少键盘字号的旧设置初始化为 12 号。旧版明确选择的“小/大”字号保留为 12/17 号；原“标准”按新的固定 15、浮动 17 号初始化。新值参与主进程与输入法进程的共享设置同步。保存失败时不发布新设置。

新增动作沿用正式直通转换流程：原表命令映射为闭集动作及参数，再由 Rust 和 ArkTS 分别校验。原始 `$cmd(...)` 字符串不会被解释执行。

测试与构建记录见 [2026-09-09 验证报告](https://github.com/JayusChi/shuangyu-ime-harmonyos/blob/f343416795303a3e844bcc80463191d122856c32/docs/evidence/2026-09-09-direct-display-settings/README.md)。

`ojz` 的字号用于键帽字母和数字，功能键文字保持略小；键高、固定候选字号和浮动候选字号独立保存。选择后立即刷新键盘，旋转屏幕、切换键盘结构或重新启动输入法后继续使用保存值。
