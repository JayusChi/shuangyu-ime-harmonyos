# 拼音双拼客户反馈修复（2026-09-15）

## 1. 句中固定二字简拼

复用“词库与个性化 → 我的词库”的固顶词条。新增词条时填写词条、两字母编码，动作选“固顶”；也可以导入本次附带的 `outputs/shuangpin-feedback-20260915/example-user-lexicon.txt`：

```text
双拼	up#固
怎么	zm#固
```

以上两字段间是 TAB。生产词库验证 `woysup → 我用双拼`、`uphfhc → 双拼很好`、`nizmbuxk → 你怎么不行`，以及 `ni'zm'bu'xk`。这项句内约束原已实现，本次补充客户 `zm` 示例与整句上屏回归，无需新增词库格式。

适用范围：小鹤双拼、恰好两个汉字、两个不能组成完整音节的声母码，且位于 1–2、3–4、5–6……码位。分音符不计码位，但不能在固定二码内部切开。合法音节、跨奇偶对的片段按原解析；同码多条固顶时句中采用源顺序第一条。支持修改、删除、热重载及重启保留。示例词条未自动写入用户个人词库。

## 2. 句末单字母

原因：整句查询已支持未完成声母，但 `a/e/o` 不在声母映射中，因此句末 `a` 没加入整句解码。旧版本 `buuinia` 的候选与 `buuini` 相同，遗漏最后一码。

修复：将待输入的 `a/e/o` 作为零声母音节的前缀参与查询，保留可继续补全、退格的状态和一码消费长度。`buuinia`、`bu'ui'ni'a` 均可选出“不是你啊”；上屏后消费全部 7 个字母并结束组合。单字母是简拼前缀，因此 `a` 也会召回“爱”等候选，不承诺“啊”固定第一；完整 `aa` 仍按原规则解析。

回归包含 `nia/nie/nio`、补全 `aa/ee/oo` 后退格恢复，以及先选“你好”后保留并选择末尾 `a`。

## 3. 分号直接上屏

原因：拼音、双拼沿用了码表方案的第二候选／分号引导分支。

修复：小鹤双拼、全拼和九键拼音的普通分号走标点输入。空输入直接插入；有候选时先提交首候选再插入分号；有编码但无候选时清理编码再插入。软键盘与实体键盘均遵循当前中英文标点设置（`；` 或 `;`），后续字母继续正常输入。补全实体键盘仅上报 KeyCode 时的 Shift+分号 → 冒号映射。小鹤音形码表保留第二候选与符号引导行为。

测试覆盖候选数 0/1/3、队列中仍有输入、unicodeChar 与 KeyCode 两条路径、Ctrl 组合键、软硬键盘、中英文标点以及全拼／九键方案；原码表引导测试明确使用码表方案的测试引擎。
