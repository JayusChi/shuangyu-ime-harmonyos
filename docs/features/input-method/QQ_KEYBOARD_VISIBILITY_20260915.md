# QQ 聊天窗口提前弹出键盘

## 客户反馈

进入 QQ 群聊或个人聊天窗口时，不应直接弹出键盘；点击输入框后才应弹出。此前提前弹出的键盘不能直接输入，还需要点击输入框获得焦点。

## 代码原因与修复

`InputPanelController.handleInputStart()` 原先在触屏模式下直接调用面板显示流程，把输入法与编辑器绑定成功当作显示键盘的请求。

现在每次建立输入会话都会清除旧的显示请求，保持面板隐藏，等待系统 `keyboardShow` 事件。`keyboardHide`、`inputStop` 和销毁都会清除请求，快速切换窗口时的过期异步显示仍通过生命周期代次检查撤销。

软硬键盘模式切换只保留当前会话有效的系统显示请求；没有请求时切回触屏模式也不会自行弹出键盘。焦点仍由宿主应用和系统管理。
