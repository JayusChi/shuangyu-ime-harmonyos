# 数字键盘便捷输入

数字键盘按一次“=”进入便捷输入，再输入内容；连续按两次“=”直接输出等号。
普通数字、密码和电话专用输入框继续遵循输入框限制。

| 输入（含引导键） | 候选，按顺序 |
| --- | --- |
| =1234.5 | 壹仟贰佰叁拾肆元伍角整 |
| =2026.8. | 2026年8月 |
| =2026.5.5 | 2026年5月5日；2026-05-05 |
| =123+5*6 | 123+5*6=153；153 |
| =OpenAI | OpenAI |

有候选时，“=”等同空格，选择第一候选；数字键盘的粘贴键选择第二候选，只有一个候选则选择这一项。无候选时粘贴键保留粘贴功能。

进入便捷输入后可以返回字母键盘继续输入临时英文，大小写按输入保留；选择候选后回到原输入方案。退格修改便捷输入，Esc 取消。普通数字键在便捷输入过程中用于编辑数字，不充当候选序号。

实体键盘在中文输入空闲时以单引号作为引导键，例如 '2026.5.5。连续按两次单引号交替输出左单引号‘和右单引号’。已有普通中文编码时，单引号保留第三候选或拼音分词行为。空格确认候选，也可点击候选或用方向键选中后按空格。

日期校验真实年月日和闰年，不产生其他日期格式。金额支持最多16位整数和2位小数。算式支持加减乘除及正负数，先乘除后加减；结果最多保留10位小数并四舍五入，去掉末尾零。除零、溢出、非法日期或尚未完整的表达式不生成候选，可以退格修改。单次便捷输入最长128个 ASCII 字符（含引导键）。

候选在 Rust 引擎统一生成，音形、双拼、全拼使用相同规则；经过 C FFI、N-API、输入队列及候选窗口接入。
