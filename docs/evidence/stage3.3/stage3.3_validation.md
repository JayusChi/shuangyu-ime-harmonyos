## 兼容性与待定规则

- ArkTS interface/Rust ABI 版本保持 2；新增 C ABI 符号与 JSON 字段随 HAP 原子升级，不支持桥接库混装。
- 显式分词当前只开放给小鹤双拼。码表 fixture 后端返回 `INVALID_ARGUMENT`。
- 仅完整或歧义尾段允许追加边界；空组合、连续边界和不完整尾段拒绝且不改状态。
- 真实 ARM64 设备尚未执行；现有覆盖为 ARM64 交叉构建和 x86_64 手机/平板模拟器。
- 独立的手机横屏形态尚未执行；当前横屏覆盖来自 2880×1920 Pad。既有 HDC DisplayManager 旋转尝试不会改变手机模拟器截图与布局树，因此不把它计作手机横屏通过。
- 既有 Stage 10 全流程在手机上执行到中文候选、退格、空格提交、英文 Shift/Caps、数字/符号切换均通过；随后因系统密码输入路由与旧脚本预期不同，在“应用安全键盘保留 Shift”旧断言处停止。该环境差异不属于 3.3 定向门禁，未计为本阶段通过项。
