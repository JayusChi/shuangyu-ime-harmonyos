# 候选回删、上档符号边距与自适应字号

日期：2026-09-11。

## 修复行为

- 下滑回删：存在编码或候选时只取消未上屏输入。清理失败或输入会话在等待期间变化时，不清空新的候选，也不删除正文。无编码和候选时删除当前行。`oui` 直通命令仍执行其原有整行删除行为。
- 设置 → 键盘与外观：新增“上档符号右边距”，默认由原先写死的 7 vp 增至 10 vp，可在 0–16 vp 内调整。
- 同页新增“键盘字号增减”和“恢复自适应字号”。默认字号按屏幕逻辑短边计算：`round(12 × min(widthPx, heightPx) / density / 360)`，默认范围 12–24；加上用户增减量后限制在 8–32。横竖屏不改变默认字号；键盘高度设置不改变字号。
- 兼容旧的 `keyboardFontSize` 存储刻度，以 `keyboardFontSize - 12` 表示增减量（-4 至 +20）。旧默认 12 对应零调整，旧 15 对应 +3；`ojz` 的默认项展示为“自适应字号”，原有 +2/-1 动作继续生效。
- 设置版本 24。右边距覆盖默认值、复制、比较、迁移、偏好存储、共享设置快照及运行时刷新。
