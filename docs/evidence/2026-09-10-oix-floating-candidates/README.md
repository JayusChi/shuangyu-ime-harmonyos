# oix 查形与浮动候选窗修复

日期：2026-09-10。使用说明见 [网页查形直通](../../features/direct-control/SHAPE_LOOKUP.md)。

后续安装验收发现本记录中的 `READ_PASTEBOARD` 声明会触发 `9568289`。现已改用系统粘贴按钮的临时授权，最新三端安装结果与包摘要见 [剪贴板权限安装修复](../2026-09-10-clipboard-permission-install-fix/README.md)。下文保留初轮实现与测试记录。

## 改动

- `oix` 首项为网页查形动作，候选显示查询字。按用户提供的字段顺序，优先光标前的汉字，无可用字时读取剪贴板开头汉字。只在确认候选后打开网页。
- 查询前清理输入法自身的预编辑，不提交 `oix` 或候选标签；URL 只包含经过编码的一个汉字，支持 UTF-16 代理对表示的扩展汉字。
- 首次复制查询没有剪贴板权限时，转到主应用请求系统授权，读取后打开网页；普通输入不读剪贴板。未授权或没有可用汉字时提示重试。
- 浮动候选窗取得自身 UIContext 后，使用实际字体和字重测量候选文字，按屏幕密度转换为 vp，并为边框、高亮、翻页和阴影预留空间。初次创建前仍有保守估算作为备用。
- 候选项不参与横向压缩，屏幕放不下时可以滚动；实体键盘选中的右侧候选自动滚入可见区域。编码或页码变化时回到行首。
- 卡片改为 14vp 圆角，按深浅主题提供柔和阴影，外层透明区域预留阴影空间。
