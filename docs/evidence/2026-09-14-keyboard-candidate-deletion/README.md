# 候选回删与上档符号边距复核

日期：2026-09-14。

状态：主机回归通过；本轮未进行手机、平板或真实实体键盘实测。

客户要求修复固定候选下滑回删，并增加上档符号右边距调节；补充要求实体键盘和虚拟键盘都覆盖。

## 当前实现

工作区在本轮开始前已包含这两项实现，见 [9 月 11 日记录](../2026-09-11-keyboard-customer-feedback/README.md)。本轮复核实现并补充跨输入入口的回归测试，没有重复改写产品逻辑。

- 虚拟键盘下滑回删：有编码或候选时清空待上屏输入；无编码和候选时删除当前行。清理失败时保留候选与正文。
- 实体键盘 Backspace 和虚拟键盘点按回删：组词时逐码删除，空组合时回删正文。实体 Esc 取消组词。实体输入和虚拟手势共用串行输入队列。
- `oui` 仍是显式整行删除命令，其既有回归也在本次全量测试中通过。
- 设置 → 键盘与外观 → 键盘尺寸 → 上档符号右边距：默认 10 vp（旧值 7 vp），可调 0–16 vp，数值增大向左移动。边距应用于屏幕键帽；实体键盘覆盖输入和删除行为。

## 本轮验证

新增 6 项测试，每种候选位置各 3 项，通过 `InputMethodLifecycleDispatcher.handlePhysicalKeySnapshot` 注入实体按键 DOWN/UP，并通过正式 `KeyboardController` 执行虚拟按键动作：

| 场景 | 固定候选 | 浮动候选 |
| --- | --- | --- |
| 虚拟输入后实体 Backspace 与虚拟点按交替，先删除编码，清空后才删除正文 | PASS | PASS |
| 实体字母尚在队列中立即下滑，取消候选并保留正文；重新输入无旧码残留；空组合下滑删行 | PASS | PASS |
| 实体 Esc 和虚拟下滑在预编辑清理失败时保留候选和正文，恢复后 Esc 清空候选 | PASS | PASS |

ArkTS 全量测试：**727 项通过，0 失败，0 错误，0 忽略**。既有边距默认值、范围校验、旧设置迁移、序列化、保存失败回滚及布局指标测试一并通过。Native 网关主机回归通过，包含 21 个显示／反馈动作及旧字号标签适配。

这些测试使用模拟编辑器和模拟引擎，验证真实 ArkTS 路由、控制器及状态更新，不代表原生设备手势或 USB／蓝牙键盘实测。未重新构建或安装发布包，未修改版本号。
