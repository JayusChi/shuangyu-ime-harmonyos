## 完成行为

- 小鹤音形四码唯一的直通在第四码执行。自动执行检查实际同码文本、内置动作与用户动作数量，不由显示上限或当前页数量推断唯一；有同码歧义、可继续的更长编码时等待选择。三字母菜单直通维持原行为。
- 自动 URL/目录动作执行前清理输入法预编辑；清理失败时恢复之前的编码，不拉起外部应用。动作由既有串行队列和动作协议处理，标签与地址不作普通文字上屏。
- 新增“候选设置 → 默认显示候选数”，默认 5 项，可选 1–10 项。固定栏与浮动窗共用，设置升级至 schema 23，旧安装默认 5 项，支持持久化与设置同步。
- 固定栏优先显示设定数量，超过上限、还有后续页或内容溢出可用宽度时提供右侧展开；窄屏仍可横向滚动。
- 浮动窗按设定数量测宽，为展开按钮与翻页控件预留空间；展开为独立网格，不唤起虚拟键盘。网格支持选词、翻页、收起，输入新编码或结束会话时复位。实体键盘高亮移入默认数量之外时自动展开。
- “输入设置”直接显示三个方案行：小鹤音形；小鹤双拼（26/18 键）；拼音（26/9 键）。使用原有完整 profile ID 一次切换，单选状态与实际输入设置一致。Pad 保留左右分栏，手机打开输入设置即可直接选择。
