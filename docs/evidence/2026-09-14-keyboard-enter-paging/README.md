# 自适应字号、回车上屏编码和实体方括号翻页

日期：2026-09-14。

## 行为

1. **字号**：既有自适应实现已复核。默认字号按 `round(12 × 逻辑短边 / 360)` 计算，默认范围 12–24；逻辑短边为像素短边除以像素密度。用户在“键盘与外观 → 键盘尺寸 → 键盘字号增减”中调整，0 表示自适应默认值，可一键恢复；叠加后的字号限制在 8–32。旧默认 12 对应零调整。典型 360 vp 手机默认 12，600 vp 平板默认 20，960 vp 平板默认 24，同逻辑尺寸的高分辨率手机不会被无意放大。横竖屏保留相同默认值及增减量。
2. **回车**：本轮把有组合时的回车改为上屏原始 `rawInput`，不选择候选、不执行功能动作，也不同时触发换行、搜索或发送。实体主回车、小键盘回车和虚拟键盘共用该行为。输入框接受编码后才清空引擎和候选，并记录上屏历史；编辑器拒绝／抛错时可重试。空组合时保留输入框动作，实体成对符号跳出和空格选词保留。
3. **实体翻页**：`[` 上一页、`]` 下一页的既有路由已验证可到达分页控制器；补修无 Unicode 驱动的 Shift＋方括号，避免花括号被误当翻页。页首、页尾会消费按键而不插入符号，英文、受限编辑器和系统组合快捷键保持宿主路由。
