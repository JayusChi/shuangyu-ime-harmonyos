# 正式小鹤音形数据接收与发布清单

当前状态：**SOURCE APPROVED / TECHNICAL INTAKE IN PROGRESS**。

经理已明确确认根目录 `码表` 与 `小鹤音形` 中的交付文件可以用于本项目，客户已同意采用“小鹤双拼＋小鹤音形”双链路。阶段 11.6 不再等待外部授权，当前工作是把交付资料冻结为可追溯、可转换、可重复构建的正式数据合同。

## 0. 已确认的产品边界

- [x] 现有小鹤双拼 `xiaohe` 保持默认和安全回退。
- [x] 正式音形方案 ID 使用 `xiaohe-yinxing`，显示名称“小鹤音形”。
- [x] 音形走独立 `CodeTable` 后端，不经过双拼 parser、拼音词库、整句解码或学习排序。
- [x] 11.6.1、11.6.2A、11.6.3、11.6.4 的通用基础继续复用。
- [x] fixture 继续只用于测试，不作为正式资源或生产降级数据。
- [ ] 正式 bundle 完成 11.6.2B～11.6.2C 后才能进入 Debug 查询。
- [ ] 完成 11.6.8～11.6.9 前，Release 设置页仍只开放 `xiaohe`。

## 1. 接收文件基线

已盘点到的主要资料：

| 目录/文件 | 当前判断 | 11.6.2B 动作 |
| --- | --- | --- |
| `小鹤音形/0.0.小鹤.txt` | 核心主码表候选，约 68,507 条数据记录，普通编码最长四码 | 固定 SHA-256、版本和数据行合同 |
| `小鹤音形/0.2.拼字.txt` | 独立 `ok...` 拼字表，88,020 条、最长八码，含大量扩展区字符 | 与普通四码表隔离，决定首版或延期 |
| `小鹤音形/1.0.分类.txt` | 分类/次选及少量命令记录 | 与根目录分类导出比较并指定权威版本 |
| `小鹤音形/2.1～2.9` | 一简、二简、直通、表外、全码词、符号、生僻和全码字 | 按分类逐一冻结权威文件和顺序 |
| `小鹤音形/hans2hant.txt` | 简繁映射，不是普通码表 | 单独决定是否进入首版 |
| `小鹤音形/ime.android.ini` | Android 行为与文件映射参考 | 只提取批准配置，不打包原文件 |
| 根目录 `码表` | 新导出的分类、用户覆盖、快符、直通、符号及辅助表 | 与同类 Android 文件做差异和优先级审计 |

已知技术事实：

- [x] 两个目录均为 UTF-8；部分文件带 BOM，换行存在 LF/CRLF 差异。
- [x] 拼字、表外字、二简次选等部分表在两个目录中完全一致。
- [x] 全码词、分类、符号、直通等存在版本或平台语法差异，不能自动拼接。
- [x] 文件混有普通候选、用户规则、`$cmd`、`$ddcmd`、配置头和平台命令。
- [x] Android 配置引用的部分文件未随本次资料提供，缺失功能必须决定延期或补充，不得猜造。
- [x] 配置中存在疑似凭据内容，原始 ini 不得进入 HAP、日志或测试快照。

## 2. 11.6.2B 必须完成的接收 manifest

每个接收文件必须记录：

- [ ] 稳定 source ID；
- [ ] 相对路径和文件作用；
- [ ] 接收日期、经理确认和客户确认记录；
- [ ] 字节数、物理行数、数据行数；
- [ ] UTF-8/BOM 和换行类型；
- [ ] 原始 SHA-256；
- [ ] 系统表、用户表、动作表、配置、拼字或简繁类型；
- [ ] 权威、补充、延期或拒绝状态；
- [ ] 分类 ID、显示名称、默认开关和稳定顺序；
- [ ] 与同用途文件的重复、覆盖和冲突统计；
- [ ] 允许的转换规则；
- [ ] 凭据、网络、外部程序和平台键码清理结果。

目录扫描不得决定分类顺序。任何正式记录都必须能回溯到 source ID、原文件和物理行。

## 3. 正式转换分类

### 3.1 普通系统记录

- [ ] 接受严格的 `词条<TAB>编码`；
- [ ] 去除已识别的配置头和注释；
- [ ] 编码字符集和最大长度按分类显式校验；
- [ ] 保存原始 `source_order`；
- [ ] 相同词条＋编码完全重复按冻结规则处理；
- [ ] 不使用词频或学习分重排系统候选。

### 3.2 用户覆盖

- [ ] 普通新增进入用户覆盖层；
- [ ] `#删` 按完整编码＋词条精确删除；
- [ ] `#固` 建立固顶保护；
- [ ] `#N` 使用 1-based 全局位置；
- [ ] `#删#固` 等复合导出状态转换为确定操作序列；
- [ ] 无法证明语义的组合必须拒绝并报告；
- [ ] 系统表保持不可变。

### 3.3 命令、符号和直通

首版白名单待冻结：

- [ ] 普通文本；
- [ ] 普通符号；
- [ ] 日期和时间；
- [ ] 成对符号；
- [ ] 可由现有编辑协议表达的光标/撤销动作。

默认拒绝：

- [x] Windows/Android 外部程序启动；
- [x] 未经产品设计的网络动作；
- [x] 账号、API、WebDAV 和凭据；
- [x] 无法映射的键盘扫描码；
- [x] 依赖第三方输入平台运行时的私有命令。

## 4. 正式 bundle 门禁

- [ ] manifest 显式列出所有分类、顺序、默认开关和源 SHA-256；
- [ ] 原始交付文件不由运行时解析；
- [ ] 两个干净目录构建产生完全相同的文件和 SHA-256；
- [ ] bundle 校验覆盖 magic、版本、长度、内容哈希、分类元数据和嵌套表；
- [ ] 生成接受、转换、延期、拒绝和重复统计；
- [ ] Debug 查询使用正式 bundle ID，不复用 `code-table-fixture`；
