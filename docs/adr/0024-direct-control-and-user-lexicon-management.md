# ADR 0024：直通控制与用户词库管理

- 状态：Accepted
- 日期：2026-08-10

## 背景

产品需要在不进入多层设置的情况下切换输入方案、启用或禁用音形分类词库；同时需要正式的用户词库入口，支持添加个人词、精确隐藏系统词、单条固顶、单条指定第 N 位及批量操作。既有用户词库只在引擎创建时加载，设置页也没有分类和词库管理入口。

## 决策

1. 直通命令使用封闭的 `action + target` 合同，由 `DirectControlCommand` 统一解析。实体键盘快捷键和 Ability Want 命令行入口都调用 `DirectControlService`，不能各自实现设置语义。
2. 方案切换继续使用 `SettingsController.changeScheme`；分类变更继续使用 `setXiaoheYinxingEnabledCategoryIds`。分类配置即使音形引擎当前未运行也可规范化并持久化，输入法进程通过既有设置同步应用。
3. `core` 分类始终启用。未知方案、未知分类、未知动作和多余参数均失败关闭，不做模糊匹配。
4. 用户词库的解析、规范化、统计、版本号和原子保存全部留在 Rust。ArkTS 只编辑结构化文档并提交完整文本，不复制格式验证器。
5. 保存采用内容 revision 的 compare-and-swap。多窗口持有旧 revision 时返回 `revision_conflict`，不得覆盖新文件。
6. 保存成功后，当前进程直接热重载；其他输入法进程通过仅限本包发布者的 Common Event 热重载。运行时解析或恢复失败时保留最后一个有效不可变快照。
7. interface/ABI 同步升级为 5，新增三个明确接口：运行时重载、管理文档读取、按 revision 保存。

## 结果

- 快捷键、命令行和正式设置页共享同一设置存储、规范化顺序、回滚及跨进程同步。
- `#删` 仍是“编码＋词条”的精确隐藏规则，不改写系统 bundle；`#固` 和 `#N` 保持候选完整列表分页前的硬排序语义。
- 用户词库页面支持单条编辑、搜索选择、批量动作、批量移除及多行文本合并/覆盖导入和导出。
- 不引入网络、云同步、系统词库写入、热路径读盘或 ArkTS 排序逻辑。
