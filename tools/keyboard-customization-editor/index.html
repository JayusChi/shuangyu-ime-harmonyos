右侧点选一个键，编辑宽度、显示文字和位置。可拖动按键交换位置；仅应用于 26 键文字布局。

空格space

字母和必要功能键不可删除。空格与逗号、句号放在同一行，可以避免设备自动补充标点键。此版支持编辑已有行，新增行可通过导入结构模板完成。

怎么交给输入法使用？
  1. 在这里修改颜色、图片或结构。
  2. 点击上方“导出皮肤包”或“导出结构包”。
  3. 将下载的文件传到设备，打开输入法“设置 → 数据管理 → 键盘结构与皮肤”。
  4. 选择对应的导入按钮，导入刚下载的文件。

只改外观时，导出皮肤包即可。要继续编辑，重新打开导出的文件。请在关闭窗口前导出保存。
